# Технологии бизнес-моделирования (ТБМ)

Репозиторий содержит материалы, скрипты автоматической генерации схем, диаграмм IDEF0, моделей BPMN, симуляций Bizagi и отчетов по лабораторным и практическим работам по дисциплине **«Технологии бизнес-моделирования» (ТБМ)**.

---

## 📌 Содержание проекта

- **Лабораторная работа №1:** «Разработка мнемосхемы процесса в розничном магазине самообслуживания»
  - `generate_diagram.py` — Python-скрипт (matplotlib) для построения мнемосхемы без геометрических пересечений и наложений.
  - `mnemoscheme_store.png` — сгенерированная схема в высоком разрешении (300 DPI).
  - `create_report.py` — генератор отчета в формате `.docx` по требованиям ГОСТ 7.32 (шрифты Times New Roman, полуторный интервал, ГОСТ-таблицы и рисунки).
  - `Отчет_ЛР1_ТБМ_ГОСТ.docx` — готовый отчет по ЛР №1.

- **Лабораторная работа №2:** «Функциональное моделирование предметной области (IDEF0)»
  - `generate_idef0_diagrams.py` — Python-скрипт для генерации контекстной диаграммы $A-0$ и диаграммы декомпозиции $A0$ в официальном стандарте IDEF0 с рамками, шифрами и ортогональными интерфейсными дугами ICOM (300 DPI).
  - `idef0_a_minus_0.png` — векторно-растровое изображение контекстной диаграммы $A-0$ («Выполнить розничную продажу товаров в магазине»).
  - `idef0_a0.png` — векторно-растровое изображение диаграммы декомпозиции первого уровня $A0$ (5 функциональных блоков $A1..A5$, ICOM-метки, ветвления и обратная связь товароучетной базы 1С).
  - `create_report_lr2.py` — генератор итогового отчета по ЛР №2 по ГОСТ 7.32 на основе официального титульного листа (`ТБМ_Шаблон_тит_лист_ЛР2.docx`) с включением утвержденной мнемосхемы из ЛР1, контекстной диаграммы $A-0$, декомпозиции $A0$, 4 аналитических таблиц спецификаций и глоссария.
  - `Отчет_ЛР2_ТБМ_ГОСТ.docx` — готовый отчет по ЛР №2.

- **Практические работы №1–3:** «Имитационное моделирование бизнес-процессов (BPMN / Bizagi Modeler)»
  - `generate_bizagi_screenshots.py` — генератор 8 эталонных скриншотов среды Bizagi Modeler (BPMN-модель, параметры симуляции Уровней 1–3, завершение симуляции на 6400 заявок, вкладки ресурсов и процесса).
  - Папка `bizagi_screens/` — 8 графических иллюстраций высокого качества (Рис. 1–8).
  - `create_report_pr1_3.py` — генератор итогового отчета по ПР №1–3 по ГОСТ 7.32 на основе официального титульного листа (`ТБМ_Шаблон_тит_лист_ПР.docx`) со сравнительным анализом результатов моделирования и теории массового обслуживания (СМО M/M/1).
  - `Отчет_ПР1-3_ТБМ_ГОСТ.docx` — готовый отчет по ПР №1–3.

- **Общие справочные материалы:**
  - `ИНСТРУКЦИЯ_ДЛЯ_НЕЙРОСЕТИ.md` — регламент, правила преемственности, жесткие табу преподавателя Латыповой В.А.
  - `ГОСТ 7-32.txt` — стандарты форматирования пояснительных записок и отчетов.

## 🚀 Запуск скриптов

### 1. Установка зависимостей
```bash
pip install matplotlib python-docx pillow numpy
```

### 2. Лабораторная работа №1 (Мнемосхема)
```bash
python generate_diagram.py
python create_report.py
```

### 3. Лабораторная работа №2 (IDEF0)
```bash
python generate_idef0_diagrams.py
python create_report_lr2.py
```

### 4. Практические работы №1–3 (BPMN / Bizagi)
```bash
python generate_bizagi_screenshots.py
python create_report_pr1_3.py
```
