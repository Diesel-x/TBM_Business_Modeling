# Технологии бизнес-моделирования (ТБМ)

Репозиторий содержит материалы, скрипты автоматической генерации мнемосхем и отчетов по лабораторным и практическим работам по дисциплине **«Технологии бизнес-моделирования» (ТБМ)**.

---

## 📌 Содержание проекта

- **Лабораторная работа №1:** «Разработка мнемосхемы процесса в розничном магазине самообслуживания»
  - `generate_diagram.py` — Python-скрипт (matplotlib) для построения мнемосхемы без геометрических пересечений и наложений.
  - `mnemoscheme_store.png` — сгенерированная схема в высоком разрешении (300 DPI).
  - `create_report.py` — генератор отчета в формате `.docx` по требованиям ГОСТ 7.32 (шрифты Times New Roman, полуторный интервал, ГОСТ-таблицы и рисунки).
  - `Отчет_ЛР1_ТБМ_ГОСТ_обновленный.docx` — готовый отчет по ЛР №1.
  - `ИНСТРУКЦИЯ_ДЛЯ_НЕЙРОСЕТИ.md` — подробная контекстная инструкция и правила форматирования.

---

## 🚀 Запуск скриптов

### 1. Установка зависимостей
```bash
pip install matplotlib python-docx pillow
```

### 2. Генерация мнемосхемы
```bash
python generate_diagram.py
```

### 3. Сборка отчета Word (.docx)
```bash
python create_report.py
```
